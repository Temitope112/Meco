# 🚗 Meco

CarFix is a modern automotive service booking platform built with **Next.js**, **React**, and **Tailwind CSS**.
It helps users discover trusted mechanics, explore vehicle services, and book car repairs or maintenance easily.

---

## ✨ Features

* Responsive modern landing page
* Automotive service listings
* Service details pages
* Booking and appointment UI
* About Us page
* Contact page with embedded map
* Reusable component architecture
* Clean premium UI/UX

---

## 🛠️ Tech Stack

* Next.js
* React
* TypeScript
* Tailwind CSS
* Lucide React Icons

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/yourusername/carfix.git
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```bash
http://localhost:3000
```
